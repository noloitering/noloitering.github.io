HexCraft

Supported Platforms

  • Mobile
  • Desktop/PC

Controls

LMB/Tap = Build/Cast
RMB = Command Units
P = Pause

A game originally designed for the raylib 6 release gamejam. Inspired by the Dungeon Keeper series you play as an evil witch placing horrible curses on the local townfolk to convert them to your cause. Capture territory by building monuments, with bigger cities requiring more nearby monuments to capture. Heal and Command your units using spells. Victory is achieved once you capture the castle at the end, but watch out for your mana! Source code here

Shape Wars

Supported Platforms

  • Desktop/PC

Controls

WASD/arrow keys = Move
Spacebar = Dash
LMB = Shoot
RMB = Bomb
P = Pause

A game created for my Computer Science 4300 class. Built using raylib and cross compiled to web using emscripten. You play as a brave triangle whose mission is to destroy all other shapes. Gain score by shooting, dashing, and bombing your way to victory to see how long you can last in this simple survival game! Enemies are worth more points depending on the number of sides they have and the debris that fly off them are worth double! They will start spawning quicker the longer you survive. Source code here
